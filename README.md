# Potion Fusion — Ops Console

Static pages for the Potion Fusion live-ops console and privacy policy,
served via GitHub Pages:

- `index.html` — the ops console (KPI dashboard + live-ops config editor).
  A login screen with no data of its own: everything is fetched from the
  game's Supabase project after an admin signs in.
- `privacy.html` — the player-facing privacy policy.

No secrets live here. The game itself is developed in a separate,
private repository.
